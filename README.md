# Ancient Combat

2D side-on ancient-era PvE combat game, built in Godot 4.3.

## Run

1. Install Godot 4.3 (standard build).
2. Open Godot, click Import, and select `project.godot`.
3. Press F5.

## Layout

- `scenes/` – Godot scenes
- `scripts/` – GDScript
- `assets/` – sprites and audio
- `scripts/game_feel.gd` – autoload with `hit_stop()` and `shake()`
